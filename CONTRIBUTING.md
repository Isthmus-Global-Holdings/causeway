# Contributing

Causeway is one rep's outreach tool, public so it can be read. It doesn't take
outside contributions: only collaborators can open a pull request.

Issues are welcome: a bug, a question, or an idea. Please leave out anything
about real people (names, numbers, emails).

To run your own copy, fork it and follow README → Setup. You'll need your own
HubSpot app, Cloudflare account (Worker, D1, Access), Gmail OAuth client and,
for calling, Twilio account; none of the deployed Worker's are shared.
